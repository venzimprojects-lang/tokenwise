# Measure outcomes, not promises / Проверяйте измерениями

_Last verified: 2026-11-11._

Before: note **timestamp**, model, reasoning, speed, exact task, starting five-hour and weekly *remaining percentage*. After: note the same metrics and whether the work succeeded. Compute `before remaining - after remaining` only if both readings belong to the **same unchanged window**, there was **no reset**, and no other task was consuming shared allowance. Even then, it is an observed balance change, not a guaranteed cost allocation.

Compare similar tasks and quality: number of accepted edits, retries, tools, time, and corrections. A cheaper first pass that needs three repeats may not be a saving.
