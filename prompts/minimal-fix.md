# Minimal code fix / Точечное исправление

```text
Goal: [one specific bug].
Scope: [files/modules]. Do not refactor unrelated code.
First identify the root cause and propose the smallest safe change.
Implement only the approved fix; run the targeted tests relevant to the change.
Stop once acceptance criteria are met. Report modified files, test outcomes and any remaining risk.
```

```text
Цель: [одна конкретная ошибка].
Область: [файлы/модули]. Не меняй несвязанный код.
Найди причину и внеси минимальное безопасное исправление.
Запусти только относящиеся к изменению проверки.
После выполнения критериев готовности остановись. Кратко перечисли изменения, тесты и остаточные риски.
```
