# Scoped audit / Ограниченный аудит

```text
Audit objective: [question]. Target: [path/repository/module].
Phase 1: inspect only relevant files and list evidence-based findings with severity.
Do not modify code in this phase. Separate confirmed findings from hypotheses.
Only propose follow-up checks that materially change the decision.
End with the three highest-priority actions. Stop.
```
