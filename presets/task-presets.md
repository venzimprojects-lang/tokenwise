# Task presets (starting points)

Presets are not official per-model prices or guarantees. Availability varies.

- **Planning:** Chat Instant → concrete acceptance criteria before agent execution.
- **Browser forms:** Work; lighter adequate model; Low; one section at a time; confirm saved state.
- **Focused coding:** Codex; Sol-class Low; reference only affected files; run targeted tests.
- **Deep audit:** Codex / Work; strong available model; Medium first; produce findings before any code changes.
- **Escalation:** upgrade only after evidence of failure or insufficient quality; avoid automatic full-project sweeps.
