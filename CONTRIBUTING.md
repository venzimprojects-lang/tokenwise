# Contributing

Contributions welcome: translations, accessibility improvements, better task presets, bug fixes, or sourced updates to platform behavior.

- Open an issue describing the problem and why it matters.
- For changing limits, models, billing or reset behavior: **link an official primary source, include its update date and your verification date**.
- Avoid numerical savings promises without reproducible evidence and comparable tasks.
- No screenshots containing personal accounts, usage data, browser sessions, keys, private repositories, or emails.
- Run `python3 -m unittest discover -s tests -v` and `node --check website/app.js`.
- Keep the app static, dependency-free and usable without signing in.

Security concerns: see SECURITY.md.
