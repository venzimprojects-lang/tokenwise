**TokenWise** — бесплатный русско-английский справочник с интерактивным конфигуратором задач. Он помогает подобрать режим работы, грамотно ограничить действия ИИ-агента и сравнить фактический расход лимитов. Без регистрации, сервера и API-ключей.

## Как пользоваться — три шага

1. **[Открой TokenWise](https://venzimprojects-lang.github.io/tokenwise/)** и выбери свою задачу: планирование, работа с сайтами, код, отладка или аудит.
2. Посмотри рекомендации, впиши детали задачи и **скопируй готовый промпт** в ChatGPT или Codex. Модель и уровень Reasoning выбираются в интерфейсе ChatGPT самостоятельно.
3. При желании открой **Settings → Usage** до и после задачи и введи оставшиеся проценты для сравнения. Не сравнивай показания в разных окнах, после сброса или во время параллельных задач.

## Что умеет

- Подбирать ориентировочную конфигурацию для пяти сценариев.
- Генерировать готовые ограниченные по объёму задания.
- Объяснять токены, пятчасовые и недельные лимиты, а также сбросы.
- Считать разницу показаний Usage без передачи данных с устройства.
- Давать готовые промпты и компактный шаблон `AGENTS.md`.

## Важные ограничения

- Это **независимый проект сообщества**, а не официальный инструмент OpenAI.
- Подсказки по моделям — ориентиры, **не гарантия экономии**. Дополнительные попытки могут увеличить расход.
- Проценты тарифа не равны количеству API-токенов или цене в деньгах.
- Наличие моделей и сроки сбросов зависят от тарифа. Проверяй **Settings → Usage**.
- Актуальность документации проверена **11 ноября 2026 года**.

## Для разработчиков

Исходники доступны в [website/](website/). Можно скачать репозиторий и открыть `website/index.html` локально. Для запуска сайта по большой кнопке ничего устанавливать не нужно.

```bash
python3 -m unittest discover -s tests -v
node --check website/app.js
```

Папки: `website/` — приложение, `docs/` — справочник, `prompts/` — готовые задания, `templates/` — шаблон агента, `tests/` — проверки.
