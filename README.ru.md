# TokenWise — работай с ИИ продуктивнее

[English](README.md) · [Веб-приложение (исходники)](website/index.html) · [Справочник](docs/) · [Промпты](prompts/)

**TokenWise** — бесплатный независимый справочник и интерактивный конфигуратор задач для ChatGPT, Work и Codex. Помогает выбрать разумный режим, ограничить работу агента и измерить фактический расход лимита.

## Что внутри

- Двуязычное приложение: выбор задачи → рекомендуемый режим → копируемый промпт.
- Объяснение токенов, лимитов на пять часов и неделю, аналитики Usage.
- Готовые задания для точечных правок, работы на сайтах и аудитов.
- Компактный шаблон `AGENTS.md` для Codex.
- Калькулятор *разницы показаний* Usage вручную, без отправки данных наружу.

## Как открыть веб-приложение

**Сейчас TokenWise находится в приватном репозитории, поэтому публичной ссылки на работающий сайт ещё нет.** При нажатии на `website/index.html` в GitHub откроется исходный код, а не само приложение.

Чтобы запустить приложение у себя:

1. На главной странице репозитория нажмите зелёную кнопку **Code → Download ZIP**.
2. Распакуйте скачанный архив.
3. Откройте папку `website` и дважды щёлкните по `index.html` — приложение откроется в браузере.
4. Выберите задачу, заполните детали, скопируйте промпт и используйте его в ChatGPT.

Никакой установки, API-ключей или сервера не требуется. После публичного запуска мы разместим отдельную ссылку на сайт, который будет открываться одним нажатием.

Разработчикам: публикация предусмотрена через `.github/workflows/pages.yml`, но пока отключена.

## Важные ограничения

- Это **независимый проект сообщества**, не официальный инструмент OpenAI.
- Низкий reasoning или лёгкая модель **не гарантируют** экономию: при ошибках и повторных запусках расход может вырасти.
- Work и Codex могут делить лимит; доступность моделей, периоды сброса и лимиты зависят от тарифа.
- Проценты лимита **не равны** цене в долларах или количеству токенов API.
- Никаких обещаний «минус 90%»: замеряй сопоставимые завершённые задачи.
- Актуальность документации проверена **11 ноября 2026 года**. Проверяй официальную справку перед публикацией новых цифр.

Тесты: `python3 -m unittest discover -s tests -v` и `node --check website/app.js`.

## Как пользоваться (V1.1)

1. Выберите задачу или нажмите на учебный пример с исправлением кода.
2. Следуйте блоку «Что делать с этими настройками?». Выставьте модель и Reasoning самостоятельно в ChatGPT/Codex — TokenWise не меняет настройки аккаунта.
3. Введите свою задачу, скопируйте промпт и вставьте его в ChatGPT или Codex.
4. Для оценки расхода откройте **Settings → Usage** до и после задачи. Сравнивайте значения только в рамках одного периода, без сбросов и параллельной агентной работы.

Рекомендации по моделям — ориентиры, а не точная стоимость, обещание экономии или официальные рекомендации OpenAI. Проект пока проходит приватное тестирование.
